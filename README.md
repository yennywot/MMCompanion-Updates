# MMCompanion Windows Downloads

This repository hosts **compiled Windows releases only** for MMCompanion.

- [Download the latest release](https://github.com/yennywot/MMCompanion-Updates/releases/latest)
- [View all releases](https://github.com/yennywot/MMCompanion-Updates/releases)

The application source code and development history are maintained in a separate **private** repository. No source code is published here.

A release is downloadable without a GitHub account. Windows SmartScreen may warn for an unsigned installer. Only download releases from this official repository.
